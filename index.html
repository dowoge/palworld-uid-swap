Palworld UID Swap

Re-ID the players in a Palworld world (host swaps, character transfers, co-op to dedicated migrations). It patches the GUID bytes in place and re-compresses each file to its original format.

100% in your browser. Files never leave your machine.

1. Load save files

Two pickers, each strict about what it accepts. Load this world's Level.sav with the first, and the Players/<uid>.sav files you want to re-ID with the second.

Drag .sav files here, or use the pickers below.

2. Assign new UIDs

Type the target UID for each player (32 hex characters, or the dashed form). Unchanged rows are skipped.

3. Swap & download

Applies your mapping to every loaded file, re-compresses to each file's original format, and names the outputs for you.

How to apply the downloads

  1. Back up your entire save folder first. Copy the whole world folder somewhere safe before touching anything.
  2. Find your save folder:
    • Steam / Windows: C:\Users\<you>\AppData\Local\Pal\Saved\SaveGames\<steamid>\<world>\
    • Steam Deck / Proton: …/steamapps/compatdata/<appid>/pfx/drive_c/users/steamuser/AppData/Local/Pal/Saved/SaveGames/<steamid>/<world>/
    • Dedicated server: Pal/Saved/SaveGames/0/<world>/
  3. Replace Level.sav and the Players/*.sav files with the downloads. The player files are already renamed to their new UIDs. Drop them into Players/ and delete the old-named ones.
  4. Launch the world. Every player keeps everything (inventory, pals, bases, unlocks). Only the ownership IDs change.
